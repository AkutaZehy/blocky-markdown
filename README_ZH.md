# Blocky Markdown 使用说明

一个极简主义的、无需框架的 Markdown 编辑器，提供块状编辑和层级文档导航功能。

  <img src="./preview.png" alt="preview"/>
</p>

## 功能

大纲、工作区、缓存区三列可自由调整宽度；11 种块类型；日间与夜间双主题；表格编辑器与链接编辑器；拖放式块管理；带 frontmatter 的导入/导出；内容自动写入 localStorage；无需构建。

### 层级大纲

- 列出全部块并带图标，H1-H6 标题各带层级缩进
- 点击 ▼/▶ 展开/折叠，点击任意项跳转到对应块
- 改动立即反映

### 可调整布局

- 三列：大纲 | 工作区 | 缓存区，列间竖线分隔符可拖动
- 每个侧边栏最小 150px、最大 500px；移动设备上折叠为垂直布局

### 增强表格编辑器

- 分屏视图：左侧网格、右侧内容编辑器，单击单元格在专用文本区域中编辑
- 动态添加/删除行列，所有操作都保留内容
- 单元格编辑器内提供"插入链接"按钮

### 超链接编辑器

- 可用于段落、列表和表格单元格，通过"插入链接"按钮打开
- 字段：链接文本、URL 与可选标题；链接插入在光标所在位置
- 生成 `[text](url "title")` 语法

### 块管理

- 在工作区与缓存区之间拖放块，边框高亮标出放置目标
- 箭头按钮 ↑↓ 交换相邻块，按钮行悬停时浮现，触屏设备常显
- 缓存区存放块而非删除；永久删除仅在缓存区可用，需确认

## 主题系统

- **Daytime（默认）**——简洁的黑白设计，等宽字体清晰易读，无装饰元素，专注写作
- **Nightcore（深色模式）**——柔和的深色（#1A1A1A 背景），非纯黑色，对比度良好，长时间使用护眼

点击页眉的 ☀/🌙 按钮切换主题。

## 支持的块类型

所有块使用简洁的 HTML 风格标签（无 emoji）：

- **文本**——`[p]` 段落块、`[h]` 标题（H1-H6，带级别选择器）、`[list]` 有序或无序列表、`[quote]` 引用块
- **结构**——`[frontmatter]` Jekyll/Hugo YAML 前置数据、`[hr]` 水平分隔线、`[br]` 换行符
- **代码与标记**——`[code]` 带语言标签的代码块、`[html]` 原始 HTML 块
- **渲染**——`[table]` 交互式表格编辑器、`[mermaid]` Mermaid 图表支持

## 使用方法

### 1）导入

- 用任意静态服务器托管本目录后在浏览器打开——原生 ES modules 不支持 `file://` 直开（例如 `python -m http.server` 或 `npx serve`）。无需安装依赖或构建。
- 点击 **↓ Import**，粘贴 Markdown（支持 frontmatter），确认导入。连续段落会自动合并，导入前会记录历史快照。
- 也可以直接粘贴仓库自带的 [`example.md`](./example.md)——一页覆盖从表格到 Mermaid 图表的全部块类型。

### 2）编辑

- **添加块**：使用工具栏标签（[p]、[h]、[list] 等），用 **Add → Start/End** 切换插入位置。
- **大纲**：仅显示标题，层级配色，仅当存在子级才显示折叠箭头；单击即折叠/展开并跳转。
- **重排**：拖拽到目标块前/后；顶部/上/下/底按钮或点击 **#N** 序号设置位置，均按数组顺序重新插入。可移到 **Cache**，也可从缓存恢复到工作区末尾。
- **编辑模式**：单击块进入行内编辑；**Edit/Done** 提供专注模式。底部 Tips 显示上下文提示。
- **预览**：**Preview/Edit** 开关渲染当前工作区；每个块的预览区也会就地渲染自身 Markdown（无 Marked 时回退为纯文本）。
- **撤销/重做**：按钮或 **Ctrl+Z / Ctrl+Y**，历史步数可通过 **History** 设置（默认 100）。支持 **Clear Workspace/Cache**，拖拽分隔条可调整各列宽度。所有按钮/大纲/折叠/块控件悬停有提示。

### 3）导出

- 点击 **↑ Export**（或 **Ctrl+S**）打开导出弹窗，可复制或下载导出的 Markdown。

### 4）体验设置

- **主题**：☀/🌙 切换并本地记忆。
- **历史步数**：通过 **History** 弹窗设置。
- **自动保存**：内容自动写入 localStorage。
- **预览切换与底部提示栏**：便于确认当前操作或悬停控件信息。

## 使用技术

- **HTML5** 结构；**CSS3** 带 CSS 变量的双主题；**JavaScript ES Modules** 应用逻辑，原生加载、免构建
- **Marked.js** Markdown 解析（带备用方案）；**DOMPurify** 预览 HTML 消毒
- **Mermaid.js** 渲染预览中的图表（按需懒加载）

## 浏览器兼容性

支持所有现代浏览器：原生 ES modules、CSS Grid 与 Flexbox、CSS 自定义属性、LocalStorage API、拖放 API，以及鼠标事件（用于调整大小）。

## 已知缺陷（本地使用）

基于当前功能与实现，作为本地工作软件时（不考虑持久化和内容安全）存在的主要缺陷：

1. **历史记录仅存于内存**——撤销/重做保留在会话内，默认最大 100 步（可配置），刷新后丢失。
2. **预览不执行页面脚本**——预览经 `marked` 渲染并由 DOMPurify 消毒，页面内脚本/样式不执行；Mermaid 图表为懒加载渲染。
3. **导入/导出保真度有限**——`js/utils/markdown.js` 的 `MarkdownUtils.parseImport` 依赖行级规则，不支持 setext 标题、`~~~` 代码围栏、对齐表格/嵌套列表等复杂结构；HTML 块按行累积，直到出现含闭合标签的行，独占一行的自闭合 HTML（如 `<p>...</p>`）会把后续行并入同一块，把 HTML 块放在文档末尾可规避（自带 `example.md` 即如此组织）；同文件的 `MarkdownUtils.exportBlocks` 仅拼接 `content` 字段，复杂 Markdown 往返易变形，frontmatter 也仅识别文件开头。
4. **触控/键盘可用性不足**——面板分隔与拖拽仅监听鼠标/HTML5 drag 事件（`setupResizer`、`DragDropManager`），触屏设备无法调整或重排，也未提供键盘操作替代。
5. **块编辑丢失格式细节**——表格编辑器用单行 `<input>` 重建单元格（`TableEditorManager.confirm`），保留列对齐标记但不支持单元格内多行内容；代码块语言解析只接受 `\w+` 形式的语言标签（`BlockFactory` 的正则不涵盖 `c#`、`c++`），这些语言会被截断。
